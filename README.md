# ⚡ SmartGovControl

**SmartGovControl** — это комплексный системный твик и игровой комбайн для Android-устройств (с поддержкой KernelSU и APatch), разработанный с акцентом на тонкое управление производительностью железа и киберспортивные возможности.

---

## ⚙️ Как он работает под капотом

### 🚀 Управление производительностью (Auto-Perf и Планировщик)
Модуль постоянно мониторит активность системы через фоновые скрипты (`service.sh`). При запуске добавленной в список игры (`auto_perf.txt`) активируется высокопроизводительный профиль процессора и видеоускорителя. Интеллектуальный сканер фокуса (`topResumedActivity`) защищает игровой режим от случайных сбросов при открытии шторки уведомлений или регулировке громкости.

### 🕹 Аппаратные макросы без детекта (`touch_injector`)
Для реализации макросов модуль не использует стандартные уязвимые службы доступности (Accessibility Services). Вместо этого задействуется нативный C++ бинарник `touch_injector`, который осуществляет прямой впрыск событий ввода на уровне ядра Linux (`/dev/input`), полностью имитируя реальные касания пальцем.

### 🎮 Игровой оверлей (Game Space)
Сервис оверлея (`GameOverlayService`) запускается как foreground-служба только во время игровой сессии. Он выводит телеметрию (FPS, температуры, частоты), управляет кастомным прицелом, блокировкой жестов и рисует по бокам экрана тонкие полупрозрачные индикаторы для быстрого вызова меню. При выходе на рабочий стол оверлей мгновенно выгружается из памяти.

### 🎞 Генерация кадров
В модуль интегрирован удобный встроенный установщик приложения-компаньона, позволяющий задействовать технологии интерполяции кадров для повышения плавной картинки в поддерживаемых проектах.

### 🔋 Энергосбережение и питание
* **Deep Sleep (Глубокий сон):** При выключении экрана скрипт принудительно снижает частоты процессора и GPU до минимальных значений.
* **Bypass Charging (Обходная зарядка):** Перенаправляет питание в обход аккумулятора, снижая нагрев смартфона во время долгих игровых сессий.
